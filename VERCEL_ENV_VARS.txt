📋 INSTRUCTIONS:
1. Go to: https://vercel.com/dashboard
2. Select your project
3. Go to: Settings → Environment Variables
4. Add each variable below
5. For each one, select ALL environments (Production, Preview, Development)
6. Click "Save" after each one
7. Redeploy your project after adding all variables

═══════════════════════════════════════════════════════════════════

🔥 FIREBASE VARIABLES (6 required)
───────────────────────────────────────────────────────────────────

Name:  NEXT_PUBLIC_FIREBASE_API_KEY
Value: [Get from Firebase Console → Project Settings → Web App Config]

Name:  NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN
Value: [Usually: your-project-id.firebaseapp.com]

Name:  NEXT_PUBLIC_FIREBASE_PROJECT_ID
Value: [Your Firebase project ID]

Name:  NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET
Value: [Usually: your-project-id.appspot.com]

Name:  NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID
Value: [Numeric ID from Firebase config]

Name:  NEXT_PUBLIC_FIREBASE_APP_ID
Value: [Starts with "1:" from Firebase config]
